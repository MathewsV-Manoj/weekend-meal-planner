# Weekend Meal Planner

> A simple weekend food plan that leaves room for leftovers and changing your mind.

## How to use it

- Write down a few meals you would genuinely enjoy.
- Make one short grocery list from those meals.
- Keep one easy backup meal for the day plans go sideways.

## A small note to yourself

The best plan is the one that makes the weekend feel easier.
